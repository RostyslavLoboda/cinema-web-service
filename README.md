# Вебсервіс з підтримки діяльності кінотеатру

## Призначення та функціональність
Автоматизація онлайн-продажу квитків, інтерактивний вибір місць у залі, попереднє замовлення з кінобару та валідація QR-кодів контролерами.

## Технології
- **Backend:** C#, ASP.NET Core Web API, Entity Framework Core
- **Database:** PostgreSQL
- **Frontend:** HTML5, CSS3, JavaScript

## Запуск
1. Клонувати репозиторій: 'git clone <URL>'
2. Запустити API: 'dotnet run --project src/Server'
