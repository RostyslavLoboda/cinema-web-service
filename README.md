# Вебсервіс з підтримки діяльності кінотеатру (Cinema Web Service)

## Призначення системи
Програмна система призначена для комплексної автоматизації процесів обслуговування відвідувачів та внутрішнього адміністрування кінотеатру: від онлайн-продажу квитків і бронювання місць у реальному часі до попереднього замовлення продукції кінобару та контролю входу глядачів до залів за допомогою QR-кодів.

## Короткий опис функціональності
Система реалізована за трирівневою клієнт-серверною архітектурою та забезпечує наступні можливості:
* **Для відвідувачів (клієнтів):**
  * перегляд актуальної афіші фільмів, трейлерів та розкладу сеансів;
  * інтерактивний вибір вільних місць на схемі кінозалу з автоматичним блокуванням обраних крісел на 10–15 хвилин для проведення оплати[cite: 14, 17];
  * попереднє замовлення попкорну та напоїв у кінобарі разом із купівлею квитка;
  * безпечна онлайн-оплата та отримання електронного PDF-квитка з унікальним зашифрованим QR-кодом.
* **Для контролерів залу:**
  * миттєве сканування QR-кодів вхідних квитків через камеру мобільного пристрою з перевіркою дійсності та фіксацією у журналі сканувань.
* **Для адміністраторів:**
  * управління каталогом фільмів, формування сітки сеансів (із автоматичною перевіркою часових накладок у залах) та налаштування цінових категорій (Standard / VIP).

## Використані технології
* **Клієнтська частина (Presentation Tier):** HTML5, CSS3, JavaScript (Single Page Application / PWA для мобільного сканера).
* **Серверна частина (Business Logic Tier):** C#, ASP.NET Core Web API, RESTful API, WebSockets (для синхронізації зайнятості місць у реальному часі).
* **Рівень даних (Data Access Tier):** PostgreSQL, Entity Framework Core (ORM).
* **Зовнішні сервіси та інтеграції:** Stripe / LiqPay REST API (обробка платежів), SendGrid / Telegram Bot API (розсилка електронних квитків та сповіщень).

## Структура проєкту
* `docs/` — проєктна та архітектурна документація.
* `scr/Client/` — клієнтський веб-інтерфейс та модулі взаємодії з користувачем.
* `scr/Server/` — серверна логіка, контролери API та моделі даних.
* `tests/` — модульні та інтеграційні тести системи.
